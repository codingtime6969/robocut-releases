## Help and bug reports

For help with access, editing, cancellation or refund requests, contact support@robocut.pro. Product and early-access details: [robocut.pro](https://robocut.pro/).

In RoboCut, use **Report a bug** to describe the problem and create an encrypted support package containing diagnostics and available project analysis. Review the inclusion details before sending the attached email draft. Transcript and analysis content may be included; source video and credentials are excluded.

Please do not post licence keys, source footage, transcripts, support packages or private project information in public GitHub issues.
