# RoboCut downloads
This repository hosts RoboCut Windows installers and release notes. Application source code is not published here.
## Release status
The v1 early-access release is being prepared. No v1 installer is available yet.
When a release is available, download its Windows installer from [Releases](https://github.com/codingtime6969/robocut-releases/releases). Save your project and close RoboCut before installing an update.
## Help and bug reports
For help with access or editing, contact dave1233345@gmail.com.
In RoboCut, use **Report a bug** to describe the problem and create an encrypted support package containing diagnostics and available project analysis. Review the package contents before sending the attached email draft. Source video and credentials are excluded.
Please do not post licence keys, source footage, transcripts, support packages or private project information in public GitHub issues.
